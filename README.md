# 창플 - Dodgeball Math Stars

이런 분위기의 그림으로 피구 게임을 하는데 아이들이 손으로 공을 던져서 사람을 맞추는 게임을 만들어 줄 수 있어? 근데 이게 학습앱에 들어갈거기 때문에 사람 을 맞춰서 아웃시킬때마다 원래 있는 사람수와 내가 공으로 아웃시킨 사람의 수를 알려줘서 아웃시킨 후 몇명이 남았는지 계산해서 입력해야 다음 공을 던질 기회를 주는거야 그래서 공은 화면에서 나와 젤 가까운 곳에 둬서 드래그를 했을때 조정하는 방향으로 날라갈 수 있게 해주고 전체 화면 자체는 저 내가 준 사진 같은 느낌으로 그림으로 만들어 주고 나는 내 칸 안에서 상대편한테 공을 던지는 듯한 느낌이 들 수 있는 게임을 만들어줘
